# Metalworks text ID comparison (Pegasus vs LSB)

Generated by `tools/compare_metalworks_text_ids.py` against **LSB `upstream/base`**.

## Files (open in Excel / Google Sheets)

| File | Contents |
|------|----------|
| `metalworks_text_id_comparison.csv` | **Full report** — every `IDs.lua` constant, NPC script reference, DefaultActions entry, and resolved numeric IDs |
| `metalworks_text_id_summary.csv` | **Differences only** — rows where Pegasus ≠ LSB or scripts differ |
| `metalworks_external_text_refs.csv` | Missions/quests/shop globals outside `zones/Metalworks/` that use `metalworksID.text.*` |

## Column guide

| Column | Meaning |
|--------|---------|
| **Category** | `IDs.lua`, `NPC/Zone Script`, `DefaultActions`, or `External script` |
| **NPC_or_Entity** | NPC name, door (`_6le`), or `(zone constant)` |
| **Source_File** | Lua path under `scripts/` |
| **Reference_Type** | `text_constant`, `ID.text key`, `showText key`, `startEvent`, `default startEvent`, etc. |
| **Reference** | Constant name, event number, or `KEY+offset` |
| **Sample_Text** | Comment from `IDs.lua` (retail string hint) when available |
| **Pegasus_Value** | Numeric message ID on this server (or event ID for cutscenes) |
| **LSB_Value** | Numeric ID from LSB `upstream/base` |
| **Match** | `YES` / `NO` / `SCRIPT_DIFF` / `SAME_SCRIPT` |
| **Notes** | Delta (`Pegasus-LSB=2`), or context |
